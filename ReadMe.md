# SpyKids — DECO2850/7285 Team Project

**Course:** DECO2850/DECO7285 Studio 2 — Interaction Design, Semester 2 2026

## Project Overview

This repository holds the team's work for Studio 2, investigating **left-behind children** — children who remain in their hometowns while parents migrate for work.

**Research question:**
How does parental absence affect left-behind children's emotional wellbeing, guidance, and development — and what is actually needed to address this gap?

The team is exploring this problem through five lenses: **Who, How, Why, Impact, and Risks**.

## Status

Currently in the **Problem Identification** phase (no solution or design specification yet). Research is being conducted via a suite of methods — contextual inquiry, rapid ethnography, digital ethnography, mapping, and object inventory — targeting 6–10 participants across the team.
